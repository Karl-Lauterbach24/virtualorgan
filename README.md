# Virtual Organ

A Raspberry Pi based virtual pipe organ with a modern web interface.

## Features

- Web-based control interface
- MIDI playback
- Live MIDI input
- FluidSynth backend
- Multiple MIDI devices
- Registration presets
- User management
- Optional login
- HDMI kiosk mode
- Bluetooth, HDMI and analog audio output
- MusicXML support
- Shared and personal libraries

## Hardware

- Raspberry Pi 4
- Raspberry Pi 5 (recommended)
- USB MIDI keyboards
- HDMI touchscreen (optional)
